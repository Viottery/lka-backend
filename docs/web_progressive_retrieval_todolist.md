# 网页渐进检索优化 TODO

状态：实施中。目标是首屏尽快拿到有来源的概要，详细证据稳定续读，不增加摘要／审查模型调用。
执行依赖：快照存储 → 工具接入 → 相关摘录 → 时效与并发 → 定向验收／审查。

## 约束与验收原则

- 保留 web.search/open/find、ToolExecutor 校验、安全门及来源角色；core 不编码网页策略。
- 不更换搜索 provider，不默认预取全部结果，不建设全局网页索引，不扩大上下文窗口。
- 不修改或提交工作区已有用户改动；本轮代码、测试、文档独立管理。
- 网页、搜索摘要均是不可信证据；抓到全文不等于模型读过或理解全文。
- 优先离线固定场景，真实网络／模型语义评测分别报告，未运行不标通过。

## A. 不可变快照与可维护存储

- [ ] 复用本地 artifact 表保存抓取边界内完整可读正文；独立索引记录所有者、版本、时限和字节数。
- [ ] open/find 共用服务；URL 查询可命中已有快照，snapshot_id 固定版本、失效不得隐式联网。
- [ ] 根会话支持同会话跨 turn；child 按 run 隔离，每次检查当前 ToolView／取消／会话状态。
- [ ] 保留原始 URL、最终 URL、fetched_at、text_sha256、抽取器版本和实际网络观察。
- [ ] 本地分页／find 使用一致 Unicode offsets；刷新只创建新版本，不混用 hash／offset。
- [ ] TTL、容量、清理均有界；缓存失败明确反馈，不伪装成空结果或最新内容。

## B. 渐进式工具合同

- [ ] search 返回公平分配的短摘要、查询时间和稳定候选引用；完整标准化响应留在本地。
- [ ] open 接受 URL／候选引用／快照，首次默认概要，offset 或 page 模式连续分页。
- [ ] 可选 query 只在本地选择相关原文，包含相邻段落；不做额外 Brave／模型查询。
- [ ] 返回有界目录、位置、上下文省略标记与续读入口；非连续摘录不冒充连续 text。
- [ ] find 默认在快照定位，沿用字面零匹配恢复，不把零匹配说成语义不存在。
- [ ] tool schemas、描述、package metadata、证据角色同步；短块保留使用已注册有界叶子阈值。
- [ ] 完整正文不重复写入每次工具结果，也不注入常规 HTTP／prompt。

## C. 时效与失败行为

- [ ] 分开 publication/provider fetch/system fetch/cache read 时间；本地 cache_hit 不诊断上游缓存。
- [ ] refresh 与 max_age_seconds 显式控制；过期固定引用报错，URL 请求可重新抓取。
- [ ] 刷新失败保留旧快照，失败不能假装成功或升级旧数据时效。
- [ ] 同会话追问能复用引用，已删除会话、不同会话、不同 child、过期权限拒绝。

## D. 有界并发和取消

- [ ] 同作用域／同请求合并抓取；不同页面并发上限、等待队列与总体 deadline 可配置。
- [ ] 所有等待有 deadline；取消检查在排队、网络前后、存储发布前生效。
- [ ] 不阻塞 FastAPI event loop；沿用 Graph 的线程执行边界，并验证 async 运行时响应性。
- [ ] 不引入默认预取／批量扩权；独立读取可走现有受控多 agent，先消除重复请求。

## E. 测试、评测与交付

- [ ] 快速搜索不抓页面、不调用模型；归档响应可恢复摘要遗漏。
- [ ] 尾部 >20k、Unicode、相邻条件、长邻居、无命中和有界目录／预算。
- [ ] open→find→续读一次 HTTP，刷新新增版本；失败刷新不损坏旧版。
- [ ] 同会话跨 turn／重启读取、跨会话／child 拒绝、失效／容量清理、权限撤销。
- [ ] 同页并发单次抓取、不同页上限、队列满、deadline、取消后无发布。
- [ ] 实际 ToolExecutor schema、规则 gate、provider prompt 交付与异步 Graph 接线。
- [ ] 小型离线 A/B：工具耗时、HTTP 次数、视图字符／token 估算、限定条件保留；不外推总响应提速。
- [ ] 保留仍 open 的真实网页语义 bad case，不用模拟模型替其关闭。
- [ ] 定向测试／Ruff／diff 检查、独立审查、API／用法／结果报告与本轮独立 Git 提交。
