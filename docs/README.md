## 文档约定

- 说明以当前实现和可用配置为准，不把长期愿景写成已交付功能。
- 安装和维护步骤使用通用路径，不携带某台电脑的账号、授权或部署记录。
- 后端与前端桌宠独立维护，客户端界面细节由对应前端项目说明。
- 开发清单、设计草稿、测试报告与历史运行产物仅用于本地工作区，
  不随发布文档提交，也不是安装或运行所必需。
